# Звернення до команди Ultrahuman

Вітаю команду Ultrahuman!

Я — українськомовний користувач Ultrahuman і хочу запропонувати добровольчий пакет української локалізації для мобільного застосунку Ultrahuman на платформі Android.

Для зручного та прозорого розгляду я підготував відкрите сховище з готовими українськими файлами ресурсів, посібником інтеграції та зручними для імпорту табличними форматами:

https://github.com/Tarasevych/Ultrahuman

Це сховище не містить виконуваних файлів застосунку, закритих двійкових компонентів, робочих журналів чи повних таблиць вихідного тексту. Воно містить виключно українські переклади та структуровані за ключами файли, призначені для офіційної перевірки й упровадження вашою командою розробників.

Моя мета — підтримати продукт, яким я щодня користуюся особисто, і допомогти зробити Ultrahuman доступнішим та зручнішим для українських користувачів. Якщо українську мову вдасться увімкнути в тестовій збірці або надати знімки екранів, я охоче продовжу добровольчу перевірку якості та підготую уточнення формулювань відповідно до вигляду справжнього інтерфейсу застосунку.

Я також буду радий допомогти з українським перекладом статей, оздоровчих порад та інших матеріалів, що завантажуються із сервера, якщо ваша команда надасть бажаний формат вихідних даних або відкриє доступ до робочого середовища локалізації.
