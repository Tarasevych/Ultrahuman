# Посібник інтеграції

**Мова:** Українська | [Nederlands (Нідерландська)](../nl/integratiegids.md) | [До огляду розділу](ОГЛЯД.md) | [На головну](../../ОГЛЯД.uk.md)

## 1. Додавання українських ресурсів Android

Додайте українські файли ресурсів до відповідного модуля Android, у якому зберігаються основні мовні ресурси `res/values/`:

```text
app/src/main/res/values-uk/strings.xml
app/src/main/res/values-uk/arrays.xml
app/src/main/res/values-uk/plurals.xml
```

Відповідні готові файли в цьому сховищі:

```text
localization/android/res/values-uk/strings.xml
localization/android/res/values-uk/arrays.xml
localization/android/res/values-uk/plurals.xml
```

## 2. Реєстрація української мовної локалі

У дослідженій версії застосунку вже оголошено конфігурацію мов:

```xml
android:localeConfig="@xml/locales_config"
```

До цього переліку достатньо додати українську мову:

```xml
<locale android:name="uk" />
```

Готовий зразок оновленого файлу в цьому сховищі:

```text
localization/android/res/xml/locales_config.xml
```

## 3. Пакет застосунку та мовне розділення

Встановлений пакет Android уже використовує окремі мовні частини (наприклад, нідерландську через `split_config.nl.apk`). Після додавання каталогу `values-uk` і коду `uk` до налаштувань мов конвеєр складання створить окрему українську мовну частину для поширення через Google Play.

## 4. Додавання ресурсів Compose

Застосунок також містить ресурси багатоплатформного інтерфейсу в каталозі `composeResources/com.ultrahuman.algo.resources`. Додайте туди відповідний файл:

```text
localization/composeResources/com.ultrahuman.algo.resources/values-uk/strings.commonMain.cvr
```

Таке розташування повністю відповідає наявній структурі каталогів `values-nl`, `values-pl` та інших підтримуваних мов.

## 5. Додаткові формати для імпорту

Якщо команда розробників використовує спеціалізовану систему керування перекладами, у сховищі підготовлено файли, що містять ключі та цільовий український переклад:

```text
formats/csv/*.csv
formats/json/*.json
```

Відкрите сховище навмисно не публікує таблиці з повним вихідним текстом застосунку. Інженери Ultrahuman можуть легко зіставити переклади за ключами ресурсів у своєму офіційному проєкті.

## 6. Підсумкова перевірка якості перед випуском

Перед офіційним випуском варто перевірити відображення української мови у внутрішній підписаній збірці застосунку:

- розміщення підписів на кнопках, картках, у вікнах повідомлень, на графіках, екранах налаштування кільця та у сповіщеннях;
- рядки, що надходять із сервера під час роботи застосунку і не входять до статичних ресурсів;
- коректне доставлення мовної частини через крамницю Google Play;
- відповідність стилю мовлення загальному тону продукту Ultrahuman.

Автор добровольчого перекладу готовий продовжити перевірку якості після увімкнення української мови в тестовій збірці або під час поступового розгортання оновлення.
