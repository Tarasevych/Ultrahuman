## Завантаження архіву

Архів випуску на GitHub залишається зручним для автономного перегляду, імпорту в системи перекладу або внутрішньої передачі між відділами розробки. Усі посилання вище ведуть до того самого відкритого вмісту сховища безпосередньо у веббраузері.
