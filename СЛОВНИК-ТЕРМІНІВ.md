# Словник термінів української локалізації Ultrahuman

**Мова:** Українська | [Nederlands (Нідерландська)](WOORDENLIJST.nl.md) | [На головну (README.md)](README.md) | [Український огляд](ОГЛЯД.uk.md)

Цей словник визначає єдині українські відповідники для медичних, фізіологічних та інтерфейсних понять застосунку Ultrahuman. Усі переклади виконано живою, природною українською мовою без кальок, суржику та мовного сленгу.

| Поняття в системі Ultrahuman | Український відповідник | Пояснення та правила вживання |
|---|---|---|
| Ultrahuman | Ultrahuman | Назва марки не перекладається і не транслітерується |
| Ring (як пристрій у текстах інтерфейсу) | кільце | Вживається слово «кільце» (не «перстень» і не «каблучка») |
| Ring AIR / Ring PRO / Ring RARE | Ring AIR / Ring PRO / Ring RARE | Офіційні назви моделей розумного кільця зберігаються латиницею |
| Індекс сну | індекс сну | Узагальнений показник якості та тривалості сну |
| Показник відновлення | показник відновлення | Оцінка готовності організму до навантажень (не «рахунок» і не «оцінка») |
| Індекс руху | індекс руху | Узагальнений показник денної рухової активності |
| Частота серцевих скорочень | частота серцевих скорочень / ЧСС | Кількість ударів серця за хвилину |
| Частота серцевих скорочень у спокої | ЧСС у спокої | Базовий показник серцевого ритму в стані повного спокою |
| Варіабельність серцевого ритму (HRV) | варіабельність серцевого ритму / ВСР | Зміна інтервалів між послідовними скороченнями серця |
| Насичення крові киснем (SpO₂) | насичення киснем (SpO₂) | Рівень кисню в артеріальній крові |
| Безперервний моніторинг глюкози (CGM) | давач глюкози / давач безперервного вимірювання глюкози | Пристрій для постійного відстеження рівня цукру в крові |
| Dexcom | Dexcom | Власна назва виробника давачів глюкози |
| FreeStyle Libre / Libre | FreeStyle Libre / Libre | Власна назва лінійки давачів глюкози |
| Health Connect | Health Connect | Системна служба обміну медичними даними в Android |
| Тренування | тренування | Заняття фізичними вправами або спортивна активність |
| Дихальні вправи | дихальні вправи | Керовані дихальні практики для заспокоєння чи зосередження |
| Аналітичний висновок | висновок / аналітика | Осмислене пояснення фізіологічних тенденцій користувача |
| Корисна підказка | підказка / порада | Коротке своєчасне нагадування або рекомендація щодо способу життя |
| Сполучення / Під'єднання / Синхронізація | сполучити / під'єднати / синхронізувати | Дії встановлення зв'язку та узгодження даних між кільцем і телефоном |
