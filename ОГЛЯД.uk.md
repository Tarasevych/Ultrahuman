# Українська локалізація Ultrahuman

**Мова:** Українська | [Nederlands (Нідерландська)](LEESMIJ.nl.md) | [Двомовний огляд (README.md)](README.md)

Це незалежні добровольчі матеріали української локалізації для мобільного застосунку Ultrahuman на платформі Android.

Мета цього сховища — зробити внесок відкритим, прозорим, зрозумілим для інженерів і зручним для впровадження командою Ultrahuman у разі додавання української мови в одному з наступних випусків застосунку.

## Що містить це сховище

- Українські ресурси Android для каталогу `res/values-uk/`
- Український файл ресурсів графічного середовища Compose для `com.ultrahuman.algo.resources`
- Файли з цільовим перекладом у форматах CSV та JSON для швидкого перегляду або імпорту
- Посібники інтеграції українською та нідерландською мовами
- Пропозицію щодо локалізації статей, оздоровчих порад і серверного вмісту
- Підсумок автоматичної перевірки якості без внутрішніх робочих журналів
- Узгоджений словник медичних і технічних термінів

## Чого немає у сховищі

- Немає інсталяційних файлів застосунку (`APK`)
- Немає вилучених закритих двійкових компонентів
- Немає робочих журналів чи допоміжних файлів налагодження
- Немає повної відкритої таблиці вихідних іншомовних рядків застосунку

Відкриті файли навмисно не відтворюють повний вихідний текст застосунку. Тут подано лише ключі ресурсів та український переклад, щоб офіційна команда Ultrahuman могла легко зіставити ці матеріали зі своїм основним проєктом.

## Основні файли для інтеграції

```text
localization/android/res/values-uk/strings.xml
localization/android/res/values-uk/arrays.xml
localization/android/res/values-uk/plurals.xml
localization/android/res/xml/locales_config.xml
localization/composeResources/com.ultrahuman.algo.resources/values-uk/strings.commonMain.cvr
```

## Повнота охоплення

- 3 597 рядкових ресурсів Android
- 4 видимі масиви Android (74 елементи)
- 10 ресурсів форм множини Android (40 українських відмінкових форм множини)
- 304 рядки ресурсів Compose
- 4 015 рядків перевірено автоматичним мовним контролем якості: 0 помилок, 0 попереджень

## Статус проєкту

Це не офіційне сховище компанії Ultrahuman. Це добровольчий внесок користувача Ultrahuman, підготовлений для офіційного розгляду та можливого впровадження.
